Vulnerabilidades Implementadas

OWASP Top 10:2025

A05 — Inyección SQL

El parámetro q del endpoint de búsqueda se concatena directamente en la consulta SQL sin parametrizar, permitiendo extraer datos de la base de datos med_core_db.

  • Iniciar sesión POST /login
  • Búsqueda de pacientes GET /search
OWASP Top 10:2025

A10 — Manejo de Excepciones

El endpoint /patients/<id> no valida el tipo de dato ni usa bloques try-except. Con debug=True, cualquier excepción expone el stack trace completo al cliente (CWE-209).

  • Ver perfil válido GET /patients/0
  • Payload: ruta sin parámetro (404) GET /patients/
  • Payload: texto no numérico GET /patients/abc
  • Payload: índice fuera de rango GET /patients/9999
  • Payload: caracteres especiales GET /patients/!!!!
  • Payload: URL-encoded GET /patients/%24%25%23%40
  • Payload: cadena extremadamente larga GET /patients/AAA...AAA
